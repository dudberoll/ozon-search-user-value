# Ozon Search User Value

Решение задачи «Ценность пользователей поиска» в рамках E-CUP 2026 / Ozon Tech.

## Задача

Предсказать суммарную стоимость заказов (GMV) пользователя за следующие 30 дней на основе обезличенной ежедневной активности в Поиске и Каталоге Ozon.

## План

- исследование данных и временная валидация;
- генерация агрегированных признаков;
- обучение и сравнение моделей;
- подготовка предсказаний для отправки.

## Статус

В разработке.
